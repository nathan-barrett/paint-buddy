# Reference images

Drop your own miniature photos here (`.png`, `.jpg`, `.jpeg`, `.webp`) and they'll
appear automatically in the app's **"Built-in image…"** dropdown — no config needed
(picked up via Vite `import.meta.glob`).

Then in the app: click the image to drop **pins**, and assign a paint (or a full
multi-step recipe) to each pin. Recipes, paint inventory, the shopping list, and
cross-brand matching all work off those pins.

These are your own photos, so — unlike downloaded models — they're **tracked in git**
and kept with the project.
